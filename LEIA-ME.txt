MINHA ROTINA — PWA

Atualização: peso atual inicial de 110 kg e hidratação (3,0 L em dias comuns; 3,5 L na quarta de futebol), com registro diário.

Arquivos:
- index.html: aplicativo
- manifest.webmanifest: configuração de instalação
- sw.js: cache/offline
- Controle diário de hidratação e creatina (dose configurável, padrão 5 g)
- icons/: ícones do aplicativo

PUBLICAÇÃO:
1. No GitHub, abra o repositório onde quer publicar.
2. Envie estes arquivos para a raiz do repositório (index.html, manifest.webmanifest, sw.js e a pasta icons).
3. Faça Commit changes.
4. Em Settings > Pages, habilite GitHub Pages se ainda não estiver habilitado.
5. Abra a URL HTTPS publicada no celular.

INSTALAÇÃO:
- Android/Chrome: menu ⋮ > Instalar app ou Adicionar à tela inicial.
- iPhone/Safari: Compartilhar > Adicionar à Tela de Início.

DADOS:
O progresso é salvo no armazenamento local do navegador/dispositivo. Esta versão não sincroniza automaticamente dados entre celular e computador. Para isso, seria necessário adicionar uma base de dados na nuvem e autenticação.


ATUALIZACAO: esta versao inclui metas editaveis, edicao de fichas e refeicoes, reagendamento por data, registro de treino realizado e atividades extras. Os dados continuam no localStorage V3 existente; nao limpe os dados do navegador.
